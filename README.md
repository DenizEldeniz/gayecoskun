# Psikolog Gaye Coşkun

Kumluca psikolog ve Kumluca psikoloji odaklı, Cloudflare Pages üzerinde statik tek sayfa olarak yayınlanmaya hazır web sitesi.

## Cloudflare Pages

- Framework preset: `None`
- Build command: boş bırakılabilir
- Build output directory: `/`
- Production branch: `main`

Gerçek domain bağlandığında `index.html`, `robots.txt` ve `sitemap.xml` içindeki `https://www.psikologgayecoskun.com/` adresini canlı domain ile güncelleyin.

Formspree linki geldikten sonra `index.html` içindeki `https://formspree.io/f/FORM_ID` adresi gerçek endpoint ile değiştirilmelidir.
